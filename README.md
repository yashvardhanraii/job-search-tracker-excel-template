# Job Search Tracker Excel Template

A simple Excel job search tracker and analytics dashboard template for students, graduates, career changers, and job seekers.

I created this project during my own data analyst job search to bring more structure, consistency, and visibility to the process. Instead of only applying to roles and waiting for responses, I wanted to track my applications like a real business process using clean data, useful KPIs, and a simple dashboard.

Anyone is welcome to download and use the blank tracker template for their own job search.

## Project Purpose

The purpose of this project was to turn a personal job search into a measurable reporting system.

The tracker helps answer questions such as:

- How many roles have I applied for?
- Which platforms am I using most?
- How many applications were tailored versus easy apply?
- Which states or locations am I applying in?
- How many follow-ups have I completed?
- Which applications still need follow-up?
- What is the current status of each application?

## What This Template Tracks

- Application date
- Role title
- Company name
- Location
- State
- Job platform/source
- Application effort type
- Application link
- Contact details
- Follow-up status
- Application status
- Days since applied
- Application month
- Whether follow-up is needed

## Skills Demonstrated

**Data Structuring:** Built a clean job application tracking table with consistent fields such as role title, company, location, platform, effort type, follow-up status, and application status.

**Excel Formulas and Automation:** Used calculated columns to automatically track days since applying, application month, and whether follow-up action is needed.

**KPI Reporting:** Created KPI cards to measure total applications, applications per day, days since first application, and follow-ups completed.

**Pivot Tables and Pivot Charts:** Used pivot tables and pivot charts to summarise application activity by status, platform, effort type, and location.

**Dashboard Design:** Designed a clear Excel dashboard that presents key job search metrics in a simple and easy-to-read format.

**Data Cleaning and Consistency:** Applied basic data cleaning principles to keep entries consistent, analysis-ready, and suitable for reporting.

**Process Analysis:** Turned a personal job search process into a measurable system that helps track activity, identify gaps, and support better decisions.

**Data Storytelling:** Presented job search activity as a visual story, showing where applications were going, which platforms were being used, and what follow-up actions were still needed.

## How To Use This Template

1. Download the Excel template file.
2. Add each job application as a new row in the tracker.
3. Update the status as your application progresses.
4. Record whether a follow-up has been completed.
5. Use the dashboard to review your job search activity.
6. Adjust the categories, platforms, and statuses based on your own job search process.
